# infix-sweet


Use:

#lang reader infix-sweet

or:

#reader infix-sweet


It is an alias of SRFI-110 for Racket : the curly infix expressions of SRFI 105 , and the neoteric and sweet
expressions of SRFI 110.


Install as a package with the [package manager](https://pkgs.racket-lang.org/package/infix-sweet) (could be a few hours delay from github.com to pkgs.racket-lang.org) or from Github source code.

<br>

See [documentation](https://docs.racket-lang.org/Scheme-PLUS-for-Racket/index.html).
